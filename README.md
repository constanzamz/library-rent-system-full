# Library Rent System – Frontend

Frontend application of the **Library Rent System**, developed with **Angular 20** and **TypeScript**.

The application consumes a **RESTful API** built with **ASP.NET Core** to manage clients, books, and rental orders.

## Features
- User interface for managing books, clients, and orders
- Integration with the backend REST API
- Component-based architecture
- Data handling via HTTP services

## Tech Stack
- Angular 20
- TypeScript
- HTML / CSS

## Backend
The backend API is developed separately using **ASP.NET Core**.

Backend repository: https://github.com/constanzamz/library-rent-system
